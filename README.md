# Расслябляющее приложение Funny Cat

## Описание полученных навыков
- Разработал мобильное приложение, которое позволяет просмотреть изображения котов, после чего сохранить или пропустить их по желанию
- В данном проекте придерживался Clean Architecture с вертикальной модуляризацией, MVVM для презентационного слоя
- Исплользовал Dagger для DI, Room, Kotlin Coroutines с Flow, Retrofit
- Познакомился и поработал с библиотеками: Work Manager и CameraX

Стек технологий в проекте: Kotlin Kotlin Coroutines & Flow, Clean Architecture, MVVM, Dagger, Room, Retrofit, Navigation Component, Work Manager, CameraX, Git
